# Вклад в развитие проекта (Contributing)

Спасибо за ваш интерес к улучшению нашей системной утилиты для Android! Любая помощь — будь то новые идеи, сообщения об ошибках или оптимизация кода — очень приветствуется.

## 📌 Как сообщить об ошибке (Bug Report)
Если вы нашли баг (например, некорректно отображается частота процессора, температура батареи или происходит вылет на определенной версии Android):
1. Перейдите во вкладку **Issues** в этом репозитории.
2. Создайте новый Issue и подробно опишите проблему.
3. Укажите модель устройства, версию Android и шаги для воспроизведения ошибки.

## 💡 Предложения по улучшению (Feature Requests)
Если у вас есть идея для нового экрана мониторинга железа или полезного диагностического инструмента:
* Создайте Issue с описанием того, как должна работать эта функция и чем она будет полезна пользователям.

## 🛠️ Как внести свой код
1. Сделайте **Fork** репозитория.
2. Создайте новую ветку для вашей функции (`git checkout -b feature/AmazingFeature`).
3. Закоммитьте ваши изменения (`git commit -m 'Add some AmazingFeature'`).
4. Отправьте изменения в ветку (`git push origin feature/AmazingFeature`).
5. Откройте **Pull Request** в основной репозиторий.

Спасибо за поддержку проекта!
